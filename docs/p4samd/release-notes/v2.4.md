_February 10th, 2026_

The minor release v2.4 improves the UX/UI, AI evaluation and document management.

## AI & Quality Assurance 
- **AI Quality Scoring**: More accurate AI evaluation of requirements and tests, for more realistic "Clarity" and "Coherence" metrics.
- **Test Quality Insights**: Suggestions now warn users when test execution modes are missing or when tests need manual execution.
- **Requirement Quality Table**: Users can now sort requirement tables based on AI-generated quality score. 

## Software Item (SWI) Management
- **Non-Semantic Versioning**: SWI versions now support non-semantic formats. Using one raises an insight to confirm it isn't a design error.
- **SWI Design Enforcement**: New "Error-level" insights trigger when mandatory architecture designs are missing for SWIs with Safety Class B or C.
- **SBOM Enhancements**: Licenses are now detected and included in the Software Bill of Materials (SBOM) file during dependency detection.

## Documentation & Traceability
- **Docx Compatibility**: Documentation templates now support interpolated data export to Word (.docx), with column sizes and headers rendered correctly.
- **Traceability Matrix**: Links between test entities and specific code implementations (e.g. Git URLs) are now more visible for auditing and coverage analysis.
- **Read-Only History**: Previous versions of documentation templates now appear in a dedicated history view in READ-ONLY mode, preventing accidental modifications to legacy data.

## Visualization & Usability
- **Frozen Released Versions**: Once a version is marked as "Released", the system now warns users and prevents any active modification, maintaining data integrity.
- **Test Dashboards**: New views distinguish between "Current Version Tests" and "Total Valid Tests" (including regression tests).
- **Risk Table Refactoring**: Risks now include linked vulnerabilities, SWI, and Changes in a single consolidated table view.

## System Information
- **ALM Accessibility**: A new tab shortcut opens external ALM tools directly from the P4SaMD interface.
