_November 26th, 2025_

## Verification and Testing

P4SaMD supports **Verification and Testing management**. New *Test Suites* logically group automatic and manual tests. You can now run automatic tests and retrieve their outcomes automatically from integrated tools.
Traceability is maintained automatically, and reporting uses a standardized format.

![Test Suite Management table](../img/MC-p4samd-test-suites-v2.3.0.png)

## Compliance Documentation Engine

The new Compliance Documentation Engine automates the generation of regulated artifacts.
A default IEC 62304-compliant templates set is provided for a quick startup. Customize templates extensively in our editor and enrich them with system data through the provided variables and custom structure.
Once a template is ready, generate the documentation and download it in your preferred format, for every version of your Software System.

## Roles & Permissions

v2.3 improves Roles & Permissions management: you can map every P4SaMD permission to the centralized roles of the Mia-Platform IDP. Each company can now integrate its Standard Operating Procedures (SOPs) flows in the tool, creating configured working paths for each user role.


## Minor Improvements & Bug fix

### Vulnerability Clarity
 
 Hovering over CVSS scores in the Vulnerabilities table now shows a tooltip detailing the scoring standard and total scale.
### Improved navigation & Quick Access

URLs in fields (like SWI implementation links) are now clickable.
### Risk Visibility

The Risk Management section now clearly reports the status of each risk in a dedicated column.
### Expanded Coverage

Vulnerabilities are now detected for SWIs of the "Other" type.
### Bugfixes

- Table Consistency: sorting tables by column now correctly resets pagination to page 1.
- Formatted text in Design Input descriptions is correctly rendered in the table drawers.
- Copy and Paste action: the command is enabled for the Suggested description of AI-powered Requirement evaluation.
