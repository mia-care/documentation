_December 30th, 2025_

## Performance Improvements

v2.3.1 includes a refactor of the view architecture, improving read time response and overall P4SaMD performance.

## Test Execution Enhancements

### Job ID Generation

P4SaMD now generates a job ID during test execution when the test executor does not return one after a test is triggered. This makes test tracking and traceability more reliable.

See [Automatic Test Suite Execution](../handbook/verification.md#automatic-test-suite-execution) in the Verification handbook.

## Minor Improvements & Bug Fixes

This release includes minor bug fixes and vulnerability patches.
