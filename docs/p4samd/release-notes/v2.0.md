_February 26th, 2025_

P4SaMD v2.0.0 is the first release of the platform for Software as a Medical Device (SaMD), designed to guide organizations through the complex SaMD development process. It aims to ensure compliance with regulatory requirements like FDA (US) and MDR (EU) and to simplify certification, building upon IEC 62304 and related standards.

The platform provides a workflow for managing the Software Development Lifecycle (SDLC) for cloud-based applications, integrating tools and automating key processes for device quality and compliance.

## SDLC Guidance

Support runs across the whole Software Development Lifecycle, through a pre-set path from design and approval to the implementation and release of the Software System. Key Performance Indicators (KPIs) monitor the whole SDLC for requirements, risks, tests, changes, and software items on the software system.

You can visualize and navigate release versions (released, in-progress, and planned) with key details of each. Quick access to the last worked on version lets you resume work immediately.

P4SaMD also provides insights and suggestions that guide you in the SDLC, for meeting the strict regulatory requirements with lower effort.

## Automated Documentation and Reporting

Get and download version-specific reports and entity information, always up-to-date at the moment of download.
Reports include Release Notes, Risk Reports, Test Reports (for unit, integration and system tests), Change Reports, SOUP Reports, S-BOM files, Changelogs for custom software components.

## Traceability 

P4SaMD provides end-to-end traceability by supporting links between requirements, software item design and implementation, verification, validation, risks, and changes. The real-time traceability matrix also ensures full traceability of changes via software system versions, addressing compliance with standards for high quality software, such as IEC 62304.

## Design and Development Control

Architecture design of the Software System is supported through the definition of the hierarchy of Software Items (SWI), including all the descriptive information of the items. Smart suggestions are provided when information is missing. You can classify the Software Items based on the safety classification (A,B,C) and differentiate them by type (SOUP, AI-based components, ..). A version log records the full history of every design change.

Software Item implementation is guided via shortcuts to ready-to-use modules and software components to be included in the Software System. Automatic controls guarantee constant checks of the implementation against the Software specifications, allowing early detection of anomalies. P4SaMD provides features for dependencies control (SOUP and S-BOM), approval and documentation.

## Test & Verification

Supports automated control and verification of SWI implementation against the design. It provides features for managing integration and system test and keeps the traceability to requirements. It also facilitates the SOUP design and formal verification.

## Risk Management

The risk framework supports risk identification, analysis and mitigation across all the risk management stages for the reference standard. It maintains the traceability to SWIs, Risk Control Measures and related changes if present. A customizable scale shows the overall risk levels and the related residual value after mitigations.

## Change Management

P4SaMD supports change control through the change request visualization, analysis and lifecycle, ensuring full traceability of changes.

## Configuration Management

P4SaMD relies on IDP configuration management strategies, including Public Variables management and Secret Variables management.

## P4SaMD Product information 

### Integration and Security Enhancements

Supports integration with external Application Lifecycle Management (ALM) tools (initially Jira) to synchronize project data and collect information from different sources. Cybersecurity is addressed by Access Management, Data Security policies and Network and Infrastructure Security measures, following the latest international cybersecurity guidelines.

### Compliance and Validation

P4SaMD is a validated tool, for more information please go to the [FAQ section](../faq.mdx).
